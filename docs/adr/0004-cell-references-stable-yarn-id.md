# Клетка ссылается на стабильный id нити, а не на её позицию в палитре

В `Uint16Array` сетки лежит id нити, выданный при её создании (наименьший свободный ≥ 1, 0 — пустая клетка), а не её номер в палитре. При хранении позиции перестановка нитей переписывала бы все их клетки (до 250 тыс. записей в патче ADR-0001), а удаление сдвигало бы индексы всех нитей ниже; с id перестановка — лёгкий патч палитры, а удаление — замена нити плюс патч палитры одной составной правкой. Цена — два понятия в domain: внутренний id и видимый пользователю **номер нити**. В `.kchart` id не попадают: клетки ссылаются на номера, при импорте id = номер; поэтому если история правок когда-нибудь будет переживать перезагрузку, хранилище обязано сохранять id как есть.
