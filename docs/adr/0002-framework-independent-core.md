# Ядро не зависит от Vue и canvas

Слои domain и application написаны на чистом TypeScript и не импортируют Vue, DOM и canvas; рендеринг, хранение, PDF и файлы подключаются через порты из infrastructure. Так модель и сценарии тестируются без браузера, а рендерер или UI-фреймворк можно заменить. Границы проверяет линтер, иначе со временем удобный импорт из Vue в domain размоет архитектуру.
