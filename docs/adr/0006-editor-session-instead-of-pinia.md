# Сессия редактора вместо Pinia; жест ведёт application

Состояние редактора держит один модуль application — сессия: `state` только для чтения, `dispatch(команда)` и `subscribe` на поток событий `patch` / `preview` / `replaced`. Pinia не используется: сетка — `Uint16Array` до 250 000 клеток, меняемый на месте патчами (ADR-0001), глубокая реактивность над ним бесполезна, а store сводился бы к тонкому мосту ради devtools. Вместо него presentation оборачивает сессию одним `useEditor()` (`shallowRef` + счётчик версии), а canvas-рендерер и автосохранение подписываются на сессию напрямую, без Vue, и рендерер перерисовывает только клетки из патча. Жест инструмента (мазок, линия, прямоугольник, отмена по `Esc`, предпросмотр) тоже ведёт сессия, получая pointer-события уже в координатах клеток: иначе правила «жест даёт не более одной правки» и «отменённый жест не трогает undo» жили бы во Vue и проверялись бы только e2e, а не тестами Vitest. Цена — свой механизм подписки вместо готового store и devtools Pinia.
