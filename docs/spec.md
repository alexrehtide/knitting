# Спецификация: редактор вязальных схем

Верхнеуровневая спецификация для запуска цикла wayfinder. Термины — по [CONTEXT.md](../CONTEXT.md); архитектурные решения — в [docs/adr/](adr/).

## Цель

Фронтенд-приложение для составления цветных схем для вязания (спицы, крючок): клетчатая **схема**, где каждая **клетка** — петля, окрашенная **нитью** из **палитры**. Схема печатается в PDF с **линейками** и читается на ч/б принтере благодаря **узорам заливки**.

## Рамки

- Только фронтенд, без бэкенда. Одна открытая схема за раз.
- Десктопный браузер, мышь/трекпад. Только актуальные Chrome, Edge, Firefox, Safari (последние две версии), без полифиллов.
- Интерфейс на русском; все строки — через словарь (vue-i18n).
- Деплой: GitHub Pages из `main` через GitHub Actions.

### Не входит (этап «Потом»)

Выделение / копирование / вставка / отражение; символы петель (лицевая, изнаночная и т.п.); импорт картинок и чужих форматов; раппорт; кисть больше 1×1; тач и стилус; PWA/офлайн; переназначение клавиш; библиотека из нескольких схем; сохранение истории правок между перезагрузками.

Модель клетки и обработка ввода не должны закрывать дорогу этим расширениям: содержимое клетки расширяемо, ввод — через Pointer Events, команды — через единый реестр.

## Модель

### Схема
- Конечная сетка W×H, целевой максимум ~500×500 с плавной работой.
- Каждая клетка: ссылка на нить палитры или **пустая клетка**.
- **Свойства схемы**: название, заметки (свободный текст), **плотность вязания** (петель и рядов на 10 см), **пропорция клетки** (по умолчанию 1:1, может вычисляться из плотности), **направление нумерации** (по умолчанию ряды снизу вверх, петли справа налево), **шаг выделения** (каждая N-я линия жирнее), даты создания/изменения.

### Палитра
- Упорядоченный список нитей; лимита нет, UI рассчитан на ~30.
- Нить: цвет, узор заливки, необязательное имя/артикул.
- Узоры — фиксированная библиотека из 12–16 различимых ч/б узоров. Новой нити автоматически назначается первый незанятый узор. Совпадение узоров у двух нитей разрешено, но показывается предупреждение.
- Удаление используемой нити открывает диалог **замены нити** (на другую нить или «пусто»). «Заменить нить X на Y во всей схеме» — отдельное действие.

## Редактор

### Холст
- Рабочая область рендерится в `<canvas>`.
- **Режим отображения**: цвет / узор / цвет+узор.
- Колесо — прокрутка, Ctrl+колесо — зум относительно курсора, пробел+перетаскивание и средняя кнопка — панорамирование, «вписать в окно».

### Линейки
- Линейки X (петли) и Y (ряды) закреплены у краёв видимой области.
- Нумерация следует направлению нумерации схемы; каждая N-я метка выделена.
- Под курсором подсвечиваются номера на обеих линейках и (отключаемо) ряд и столбец на сетке.
- Статус-бар показывает координаты в нумерации схемы.

### Инструменты
- **Кисть**: 1×1, протягивание с интерполяцией пропущенных клеток; Shift+клик — линия от последней точки.
- **Ластик**: делает клетки пустыми.
- **Пипетка**: берёт нить клетки (также удержанием Alt).
- **Заливка**: по 4-связности.
- **Линия**.
- **Прямоугольник**: контурный, с модификатором — залитый.

### Документ
- **Новая схема**: диалог с шириной, высотой (по умолчанию 40×40) и плотностью.
- **Изменение размера**: добавить или убрать N рядов/петель с каждой из четырёх сторон; если обрезаются непустые клетки, показывается предупреждение.
- Новая схема и импорт заменяют текущую. Если были изменения после последнего экспорта в файл, появляется диалог «Сохранить в файл / Отбросить / Отмена».
- Текущая схема автоматически сохраняется в браузере (IndexedDB) и восстанавливается при перезагрузке.

### Undo / Redo
- Одна **правка** — одна запись: мазок целиком (от нажатия до отпускания), заливка, фигура, изменение палитры, замена нити, изменение размера, изменение свойств.
- Правками не являются: зум, прокрутка, выбор инструмента и нити, режим отображения.
- Глубина — 200 правок; история живёт только в сессии.
- Реализация — обратимые патчи (ADR-0001).

### Горячие клавиши
Привязка по `event.code` (работает в русской раскладке); все команды — в едином реестре.

| Клавиша | Команда |
|---|---|
| `B` / `E` / `G` / `I` / `L` / `R` | кисть / ластик / заливка / пипетка / линия / прямоугольник |
| удержание `Alt` | временная пипетка |
| `Ctrl+Z` | отменить |
| `Ctrl+Shift+Z`, `Ctrl+Y` | повторить |
| `Ctrl+S` | экспорт `.kchart` |
| `Ctrl+O` | импорт `.kchart` |
| `Ctrl+P` | экспорт PDF |
| `Ctrl+N` / `Alt+N` | новая схема (`Alt+N` — запасной: Chrome не отдаёт Ctrl+N) |
| `1`–`9` | нить по номеру в палитре |
| `X` | переключиться между двумя последними нитями |
| `Ctrl+0` / `Ctrl+=` / `Ctrl+-` | вписать / приблизить / отдалить |
| `Tab` | следующий режим отображения |
| `?` | справка по клавишам |

## Вывод

### Файл схемы `.kchart`
- JSON с полем версии формата; при импорте старые версии проходят цепочку миграций.
- Клетки хранятся компактно (индексы нитей построчно, допускается RLE).
- Импорт битого или несовместимого файла даёт понятную ошибку и не трогает текущую схему.

### PNG
Растровый экспорт текущего режима отображения с линейками.

### PDF
- Векторный (без растра).
- Формат A4/A3, книжная или альбомная ориентация.
- Размер клетки в мм (по умолчанию ~5 мм) с учётом пропорции клетки.
- Большая схема разбивается на **листы**; на каждом повторяются линейки со сквозной нумерацией, опционально с перекрытием в 1–2 ряда/петли для склейки.
- Режим печати: цвет / узор / цвет+узор.
- Заголовок: название, размер, плотность, заметки.
- **Легенда**: нить → цвет/узор → имя → число петель этой нити.

## Архитектура

- TypeScript (strict), Vue 3 (Composition API), Vite.
- Слои (ADR-0002):
  - **domain** — схема, сетка, палитра, нить, узоры, правки и патчи, алгоритмы инструментов (линия, заливка). Чистый TS.
  - **application** — сценарии (рисовать, залить, заменить нить, изменить размер, undo/redo, импорт/экспорт) и порты (хранилище, файлы, PDF, PNG).
  - **infrastructure** — canvas-рендерер, IndexedDB, сериализация `.kchart`, генератор PDF (jsPDF или pdf-lib), PNG.
  - **presentation** — Vue-компоненты; Pinia (если нужна) — тонкий мост между application и UI.
- domain и application не импортируют Vue, DOM и canvas; границы слоёв проверяет линтер (`eslint-plugin-boundaries` или аналог).
- Сетка — плоский типизированный массив (`Uint16Array`) индексов нитей; 0 — пустая клетка.

### Качество
- ESLint + Prettier, строгий TS.
- Vitest: domain и application пишутся test-first.
- Playwright: несколько e2e-сценариев (нарисовать → undo → экспорт/импорт; печать PDF).
- CI в GitHub Actions на каждый PR: линт, типы, тесты, сборка.

## Этапы

1. **Ядро**: модель схемы, canvas-рендер сетки, линейки с подсветкой, зум/прокрутка, палитра, кисть, ластик, пипетка, undo/redo, реестр горячих клавиш, автосохранение, экспорт/импорт `.kchart`, каркас CI и деплоя.
2. **Инструменты и документ**: заливка, линия, прямоугольник, новая схема, изменение размера, замена нити, свойства схемы, узоры заливки, режимы отображения.
3. **Вывод**: PNG, PDF с листами, линейками и легендой.
4. **Потом**: см. «Не входит».
